The stacked Late Batch Bakery logo as single-ink SVG, one file per ink: `late-batch-black.svg` (#000000), `late-batch-teal.svg` (#588b8b), `late-batch-copper.svg` (#c8553d), `late-batch-brown.svg` (#513724), `late-batch-cream.svg` (#edeae4), `late-batch-sage.svg` (#cad2c5).

Each file is one flat ink and shows through `<img>`, which cannot recolour it, so pick the file whose ink matches the ground (see the pairing table in the README). Keep clear space of at least the height of the letter "L" on every side, and never set the logo smaller than 96px wide, where BAKERY stops being legible.

# Late Batch Bakery — website

Fictional bakery website for a class project by Natalia Martín Macías (third-year TSDMG, Digital Marketing Strategies). English only.

Plain HTML/CSS/JS, no build step. Open `index.html` in a browser, or use the VS Code "Live Server" extension.

```
index.html   Home (full-width dark-coffee hero with the cream logo)
about.html   About us
shop.html    Simulated shop: Bread, Cookies, Croissants + working bag (js/shop.js)
css/styles.css
assets/      logos (SVG), product photos, fonts (Pagkaki, Montserrat)
design-system/  tokens.json and README.md of the "Late Batch" design system
```

## Using this with Claude in VS Code
Open this folder in VS Code and ask Claude to edit it. `CLAUDE.md` holds the brand rules so Claude keeps the design consistent.

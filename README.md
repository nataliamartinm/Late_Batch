# Late Batch

Sitio web estático.

## Estructura

```
.
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── main.js
└── assets/
    └── img/
```

## Desarrollo local

Abre `index.html` en el navegador, o sirve la carpeta con un servidor local:

```bash
npx serve .
# o
python -m http.server 8000
```

# Late Batch design system

Before writing or changing any UI, slide, document or marketing asset for Late Batch Bakery:

1. Read `README.md` in this folder (brand rules: colour pairings, type, imagery, tone).
2. Link `tokens.css` and use its CSS variables (`--bg`, `--fg`, `--accent`, `--space-*`, `--font-display`, `--font-sans`). Never hard-code hex values.
3. Set `data-theme="light"` or `"dark"` on `<html>`.
4. Use the logos in `assets/Logos/` (pick the ink that matches the ground) and the photos in `assets/Photography/`. Never retype or redraw the logo.
5. Fonts are in `fonts/` (Pagkaki for display titles in capitals, Montserrat Regular for everything else).
6. Look at `components/*/preview.html` for how the pieces are composed.

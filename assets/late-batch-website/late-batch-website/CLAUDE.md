# Late Batch Bakery website — guidance for Claude

Static site (HTML/CSS/JS, no build). All copy is English. Follow the brand in `design-system/README.md` and `design-system/tokens.json`.

Key rules
- Colours: cornsilk #fefae0 (page), cream #edeae4, rosy-copper #c8553d, dark-coffee #3b2a22 (text), crust-brown #513724 (secondary text), ash-grey #cad2c5, dark-cyan #588b8b, ink #000.
- Category colours: bread = copper, cookies = crust-brown, croissants = dark-cyan. Copper/cyan only for text 24px and up; small text on those fills is black.
- Fonts: Pagkaki (display, capitals only, never below 28px) and Montserrat Regular 400 only (no bold). Labels: 14px, uppercase, letter-spacing .2em.
- Flat: no shadows, gradients or rounded corners. Product names in capitals, no taglines or emoji on labels.
- Logo: use the files in `assets/logos/`, never retype it. Cream logo on dark-coffee/copper/cyan, brown on cornsilk/ash-grey. Min 96px wide.
- Primary button: dark-coffee fill, cornsilk label; hover = copper fill, black label.
- The shop is a simulation (js/shop.js); prices are fictional.
